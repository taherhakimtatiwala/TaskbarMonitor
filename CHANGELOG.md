# Changelog

## [1.0.0] - 2026-10-14
### Added
- Live upload / download speed, CPU % and RAM % overlay for the Windows 11 taskbar
- Borderless, always-on-top, draggable widget with optional position lock
- Settings window: fonts, colors, opacity, corner radius, padding, layout, visible metrics
- Theme presets: Dark, Light, Neon, Minimal
- Horizontal or vertical layout; labeled or compact display; symbol or text labels
- Optional "Start with Windows" (HKCU Run key, Startup-folder fallback)
- Settings saved to `%APPDATA%\TaskbarMonitor\settings.json`
